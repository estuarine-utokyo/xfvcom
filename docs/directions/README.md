# `docs/directions/`

Task-specific delegation instructions for automated Claude Code
sessions (interactive or `claude -p` headless). Filename
convention:

```
docs/directions/YYYYMMDD_<topic-slug>.md
```

See the "Direction files" section of [`../../CLAUDE.md`](../../CLAUDE.md)
for the convention rules, the rationale, and how the files pair
with the resulting implementation commits.

These files are markdown; they sit alongside the Sphinx-built
package documentation (`api.rst`, `index.rst`, etc.) but are not
indexed by Sphinx — they are delegation artefacts, not part of the
published xfvcom user manual.
